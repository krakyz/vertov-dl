# vertov-dl · 0.1.0-alpha.1

Личный серверный загрузчик медиа: Python/FastAPI, TypeScript/Vite без React, SQLite, yt-dlp, FFmpeg и Deno. Интерфейс работает в браузере, готовые файлы передаются штатной браузерной загрузкой.

## Возможности

- Одиночные ссылки и пакетный ввод с пустой последней строкой. YouTube Mix/playlist-ссылки с ID приводятся к отдельному видео.
- Два параллельных запроса метаданных, кэш успешных результатов на 5 минут, превью фоном.
- Видео MP4, аудио MP3, выбор форматов yt-dlp; прогресс, отмена и продолжение после ошибки.
- Восстановление рабочего списка после обновления страницы, журнал всех задач.
- Библиотека сеткой, фильтры, выделение, скачивание и удаление; локальная конвертация видео в MP3 без yt-dlp.
- Фоновый ffprobe: фактические кодек, разрешение и FPS.
- Импорт Netscape cookies.txt через настройки или drag-and-drop, шифрование на сервере.
- Оригинальные названия в интерфейсе; нормализованные Unicode-имена при скачивании.
- Авторизация ключом, HttpOnly-сессия, обязательный SOCKS5 без direct fallback, проверка исходящих адресов.

Это предварительная однопользовательская alpha для доверенного администратора. Доступ по loopback/SSH-туннелю; размещение открытого сервиса в интернете не поддерживается. Работа каждого сайта не гарантируется. Плейлисты целиком, live, автоматическая CAPTCHA, PO Token provider и multi-user не реализованы.

## Быстрый запуск (Linux + Docker Compose)

Нужен SOCKS5 на хосте (по умолчанию 127.0.0.1:20170). Конфигурация использует Linux host network и не меняет существующий VPN.

```bash
python3 scripts/generate-token.py
docker compose up -d --build
```

Ключ находится в `deploy/secrets/media_auth_token.txt`; не публикуйте его. С компьютера откройте SSH-туннель:

```bash
ssh -N -L 47831:127.0.0.1:47831 USER@SERVER
```

Откройте http://127.0.0.1:47831 и введите ключ. Для другого прокси измените MEDIA_PROXY_URL в compose.yaml. Режим без прокси не предусмотрен.

## Хранение

| Данные | Лимит | Срок |
|---|---:|---:|
| Готовая библиотека | 10 ГиБ | 30 дней |
| Временные файлы ошибочных загрузок | 10 ГиБ | 7 дней |

При превышении временного лимита удаляются старые части ошибочных задач, активные задачи не вытесняются. Временный учёт включает активные download/convert-каталоги; это периодическая политика, не filesystem quota. Также остаются резерв свободного диска 2 ГиБ, лимит итогового файла 2 ГиБ и deadline 30 минут. Все значения настраиваются через MEDIA_*.

«Скрыть» завершённую задачу сохраняет файл в библиотеке; «Удалить» у ошибки очищает части. Отмена также очищает части. Передаваемый браузеру файл защищён от TTL/квоты до завершения текущего HTTP-ответа; сохранение на диск браузером не подтверждается.

## Разработка

Python 3.12 и Node 24, FFmpeg/ffprobe в PATH:

```bash
python -m pip install -r requirements.lock
python -m pip install --no-deps -e .
npm ci
npm test
npm run build
pytest -q
```

`npm run dev` запускает WebUI на :5173 с API-прокси на :47831. Переменная MEDIA_API_TARGET меняет адрес API. Python-пакет остаётся `media_loader`, переменные `MEDIA_*` и прежние browser storage keys сохранены для совместимости.
