## Границы проверки и остаточные ограничения alpha

- Локальный HTTP-сценарий подтверждает Range-докачку, но не гарантирует её для любого сайта, DASH/HLS или нестабильного VPN.
- Браузерная проверка использует синтетические данные. Реальная MP3-конвертация отдельно проверена на Windows/Linux.
- Browser save/многократные автоматические загрузки зависят от настроек браузера; HTTP-ответ не подтверждает запись на диск.
- Лимиты хранения периодические, без жёсткой filesystem quota. Активные задачи не вытесняются; нужен свободный диск.
- Несколько workers/публичный multi-user не поддерживаются. API по умолчанию loopback и SSH-туннель.
- Полное закрепление supply-chain digest и независимый аудит лицензий бинарных сборок остаются перед публичной поставкой образов.
- Схема SQLite без смены таблиц, Alembic нужен до первой миграции.

Функции после alpha и решение не внедрять break-on-existing: roadmap.md. После чистой экспортной проверки результаты дописываются в development.md.

Чистая экспортная проверка завершена: npm ci/build/test, 85 pytest в новой копии и установленном Docker-пакете, image smoke. Локальный Git main и тег v0.1.0-alpha.1 созданы без origin; исходный ZIP содержит только файлы коммита.

## Коррекция issue #9

Первоначальный bookworm-образ содержал FFmpeg, уязвимый к CVE-2026-8461. Исправление переводит runtime на trixie с проверяемым security-backport; подтверждён пакет 7:7.1.5-0+deb13u1. Новый image smoke и 89 контейнерных тестов прошли, отчёт — security-checks/issue-9.json. Старые собранные образы этим не исправляются: их нужно заменить пересобранными.
