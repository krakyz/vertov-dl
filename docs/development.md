# Разработка и проверки

## Команды

```bash
python -m pip install -r requirements.lock
python -m pip install --no-deps -e .
ruff check apps/api tests scripts/ffmpeg-local.py
ruff format --check apps/api tests scripts/ffmpeg-local.py
pytest -q
npm ci
npm run build
node --test tests/web-model.test.mjs tests/cookie-drop.test.mjs
docker build -t vertov-dl:0.1.0-alpha.1 .
```

requirements.lock фиксирует версии всего тестового окружения, включая pytest/ruff. В текущем образе они тоже установлены; разделение production/dev lock — дальнейшее уменьшение образа. Для разработки без lock есть extra test в pyproject.toml, но результат может отличаться по версиям.

Локальная проверка выполнена на Python 3.11, Node 24.14.1, npm 11.11.0. Образ использует Python 3.12 и Node 24 для сборки UI; Deno 2.9.8, yt-dlp 2026.10.26 и EJS 0.8.0.

## Выполненные проверки

- npm install: audit 0 vulnerabilities; TypeScript/Vite production build успешен.
- Ruff check и format: успешны.
- 27 pytest-проверок: успешны на Windows и внутри итогового Linux Docker-образа.
- Проверены auth/cookie tampering, CSRF, лимит тела, состояния очереди/retry/recovery, Range и запрет path traversal.
- SOCKS gateway: private/multicast targets, смешанный DNS, pinned public IP и передача байтов через тестовый upstream.
- Реальный дочерний процесс отменяется и удаляет частичные файлы; прямое Python-соединение к LAN блокируется.
- В образе проверены Deno и отказ ffmpeg открывать HTTP через protocol whitelist.
- Docker-образ собран. Серверные end-to-end результаты фиксируются отдельно в deployment-home.md.
- Пройдены серверные probe/download, передача двух файлов на домашний клиент с SHA256, Range и SSE; вход, выбор качества, ручной retry и браузерное скачивание проверены через реальный WebUI.

Starlette выдаёт предупреждение об устаревании httpx TestClient в пользу httpx2; текущие проверки проходят. Это не ошибка runtime. CI подготовлен, но запуск GitHub Actions в этом окружении не выполнялся.

Продолжение после ошибки: проверены retry с тем же ID и сохранением частей, удаление частей при DELETE, сохранение частей совпадающего формата и очистка при смене формата. Linux: 65 pytest, frontend: 18 тестов, TypeScript/Vite и Ruff прошли. Реальный сетевой обрыв/возобновление на внешнем сайте не воспроизводился.

Фоновый ffprobe: 66 pytest прошли на Windows и Linux; TypeScript/Vite, Ruff и Docker build прошли. После развёртывания runtime 746e4164a3c5 API библиотеки подтвердил обогащение всех 5 существующих файлов; у 3 видеозаписей заполнен fps. Тест с задержанным процессом подтверждает, что completed не ждёт проверки, а updated/TTL не меняется.

Локальная конвертация видео в MP3: 69 pytest прошли на Windows и Linux, 18 frontend-тестов, Vite/TypeScript и Docker build прошли. Реальный FFmpeg проверен для видео с аудио и без него. API-тест проверяет авторизацию, pending-карточку, защиту от дублирования и сохранение закреплённого источника после удаления исходной записи библиотеки.

Регрессия конвертации: результат локального worker не содержит extractor title; Manager сохраняет название исходной задачи. Добавлена проверка полного запуска через Manager, а не только прямого вызова конвертера.

Ускорение метаданных: 75 pytest на Windows/Linux, 18 frontend-тестов, Ruff и TypeScript/Vite прошли. Проверены TTL, отсутствие отрицательного кэша, порядок ответов, сброс поколения cookies, force/retry, два probe одновременно с download, ранний completed до превью и сохранение успеха при падении preview-worker.
