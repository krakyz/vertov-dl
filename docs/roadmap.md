# Roadmap vertov-dl

## 0.1.0-alpha.2 — текущая цель

Однопользовательский self-hosted Docker-сервис с WebUI. Реализованы метаданные/форматы, MP4/MP3, продолжение после ошибки, библиотека, локальная конвертация, cookies, безопасные имена, отдельная политика временных файлов и фоновый ffprobe. Исходный код MPL-2.0.

Согласованный порядок подготовки: временные файлы и докачка → нормализация имён → браузерные проверки → чистая установка Docker → оформление локального репозитория vertov-dl. Результаты проверок фиксируются в development.md и release-checklist.md.

## После alpha, не блокирует первый выпуск

Аннотация к решению о составе релиза от 2026-11-02:

- Полноценные плейлисты и каналы.
- Расширение браузера для экспорта cookies.
- PO Token provider и восстановление серверной сессии.
- Многопользовательский режим и изоляция данных.
- Автоматическое обновление yt-dlp, FFmpeg и Deno с проверкой и откатом.

Эти функции запланированы отдельно, они не выдаются за реализованные. CAPTCHA сейчас приводит к предложению обновить cookies; автоматического решения нет.

## Надёжность и следующие выпуски

- Реальные сценарии нестабильного внешнего VPN; Retry-After/backoff по сайту.
- Миграции Alembic до первого изменения схемы таблиц; идемпотентность запросов.
- Усиление сетевой изоляции worker до публичного интернет-размещения.
- Подпись образов, SBOM и закрепление базовых образов digest.
- Дополнительные автоматизированные браузерные регрессии.
- Дедупликация библиотеки. Переиспользовать готовый файл при совпадении источника, формата, качества и аудиодорожки. Для скачивания и конвертации аудио учитывать параметры результата. При сохранении объединять побайтовые копии по SHA-256. Для старых дублей предусмотреть просмотр и очистку по выбору пользователя.

## Исключено

break-on-existing не добавляем: стандартный архив yt-dlp не различает качество/формат. Rust/Tauri, трей, хоткеи, Explorer и Telegram-бот исключены из объёма.
