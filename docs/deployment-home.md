# Развёртывание vertov-dl

Каноническая схема — корневой compose.yaml, инструкции — installation.md. Локальная разработка может использовать Vite :5173 и SSH-прокси API на :47831 без пересборки образа.

Для нового пользователя нужно собирать полный образ из исходников. Внутренний source-overlay тестового сервера не является частью установки и не требуется для работы. Новый репозиторий не содержит секретов или настроек SSH.

При обновлении существующей тестовой установки сохраните прежнее имя проекта и volume. Новое имя продукта не должно создавать пустой volume вместо старого. Проверяйте healthz, версию, библиотеку и cookies после запуска. Старый ключ нужен для расшифровки существующего cookies.enc.

Размещение открытого API в интернете не поддерживается в alpha. HTTPS reverse proxy, авторизация и worker isolation требуют отдельной конфигурации/проверки. Вариант по умолчанию — loopback и SSH-туннель.
