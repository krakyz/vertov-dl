# Домашний сервер

Рекомендуется Linux Docker и уже настроенный отказоустойчивый VPN с SOCKS5 на хосте. Приложение не меняет маршруты, firewall, VPN и другие Compose-проекты.

Пример подключения — в compose.yaml; запуск, обновление и перенос данных — installation.md. Все SSH-адреса, пароли, ключи, cookies и конкретные рабочие ссылки находятся вне подготовленного репозитория.

Сетевая доступность определяется прокси/сайтом. Приложение не делает direct fallback и не отключает TLS. Host network используется для доступа к loopback SOCKS5 и сам по себе не является песочницей.
