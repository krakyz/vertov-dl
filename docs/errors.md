# Ошибки vertov-dl 0.1.0-alpha.2

Worker возвращает error_code и фиксированное безопасное сообщение. Исходное исключение, stderr, подписанные URL, cookie/header значения не выдаются пользователю и не записываются в application log. Перед эвристикой из текста удаляются URL и секретные заголовки. Классификация остаётся приблизительной.

| Код | Поведение |
|---|---|
| authentication | Нужен вход; импортировать/обновить cookies в настройках |
| challenge | Предложение обновить cookies.txt и повторить загрузку |
| rate_limited | Предлагается повторить позже |
| format | Другой preset либо проверка доступных форматов |
| access_denied | HTTP 403; причина не объявляется DPI/CAPTCHA |
| network | Не удалось получить данные через выбранный маршрут |
| unavailable | Недоступность контента текущей сессии |
| unsupported | Live/playlist/протокол/размер не поддерживается |
| unknown | Неопределённая ошибка yt-dlp |
| worker | Не удалось завершить дочерний процесс |
| timeout | Превышено время попытки |
| disk_limit | Недостаточно места или превышен лимит временного каталога |
| conversion | Ошибка локальной конвертации, в том числе отсутствие аудиодорожки |
| interrupted | Задача прервана остановкой/перезапуском |

yt-dlp имеет ограниченные внутренние повторы (2 запроса/фрагмента, 1 extractor retry). Бесконечных повторов задач нет: failed download продолжается в том же каталоге, прочие повторы создают новую задачу. Retry-After и общий circuit breaker по сайту относятся к следующему этапу.

403 — симптом, не диагноз; timeout не доказывает DPI. Deno/EJS не заменяет PO Token или интерактивную CAPTCHA. Смена прокси/IP не выполняется приложением: отказоустойчивость остаётся у v2rayA.

Код cookies: не удалось расшифровать хранилище; требуется повторный импорт. Повреждённый импорт возвращает 422 и не заменяет текущий набор.

Для authentication и challenge отображается «Обновите файл cookies.txt в настройках и повторите загрузку». Коды сохраняются раздельными, состояние остаётся failed. Это рекомендация, не подтверждение устранения проверки; автоматическое прохождение или бесконечный повтор не добавлены. UI применяет текст также к старым задачам с этими кодами.
