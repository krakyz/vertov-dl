# ADR-0001: независимый core и серверная доставка

Дата: 2026-11-01. Статус: принято для заготовки.

## Контекст

Нужен desktop-загрузчик Rust/Tauri с будущей возможностью использовать более доступную сеть домашнего или арендованного сервера. Пользователь уточнил: сервер получает метаданные, скачивает медиа и передаёт результат домашнему клиенту.

## Решение

Общий Rust core не зависит от Tauri. Local worker работает на ПК. Remote worker получает метаданные и выполняет всю загрузку/обработку на сервере. Клиент забирает готовый артефакт; прямые CDN URL между worker не переносятся. Серверное хранение временное, его срок задаёт политика доставки.

yt-dlp используется отдельным процессом с массивом аргументов. Для строгого memory-only cookies допускается будущий изолированный API-адаптер после прототипа. Не делать это обещанием текущей реализации.

## Последствия

Очередь и диагностику можно повторно использовать. Нужны две отдельные стадии прогресса: получение медиа сервером и доставка на ПК. Требуются Range, целостность, ack/TTL и квоты. Авторизация и антибот-проверка должны соответствовать сети серверного worker.
