# ADR-0004: зашифрованный импорт cookies.txt

Принято, 2026-11-02.

Пользователь запросил Netscape cookies.txt через настройки и drag-and-drop с применением к загрузкам. Содержимое принимается авторизованным API, строго проверяется и атомарно заменяет зашифрованный набор в /data/secrets/cookies.enc. AES-256-GCM реализован установленным PyCryptodome (pycryptodomex теперь явная зависимость). Отдельный ключ выводится из существующего серверного auth token через HMAC с контекстом версии. Смена auth token требует повторного импорта.

Worker читает набор при запуске, расшифровывает его в памяти и заполняет cookiejar yt-dlp. Нет открытого cookiefile, исходных cookies в SQLite/spec, их отправки обратно браузеру или автоматического сохранения обновлённых сайтом cookies. Шифрование защищает отдельный файл на диске, не работающий сервер с доступом к ключу.

Статус сообщает только счётчики и ближайший срок истечения. Сессионные cookies не имеют фиксированного срока; сайт может отозвать авторизацию в любое время. Импорт не гарантирует повышение качества форматов и не решает CAPTCHA. Один набор общий для доверенного администратора; multi-user и прямой импорт браузерных профилей отложены.
