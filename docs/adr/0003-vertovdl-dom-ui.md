# ADR-0003: vertov-dl на TypeScript и DOM-шаблонах

Статус: принято, 2026-11-02. Уточняет frontend из ADR-0002.

Пользователь предоставил готовый HTML/CSS/JS-макет и запросил перенос существующей логики, допуская ограничения сервиса. Сохраняем его разметку, стили и SVG, подключая API через TypeScript. React и его типы удалены из зависимостей. Vite остаётся для разработки, API proxy и production build.

Модули разделяют API, обработку ссылок/типов, карточки/историю и контроллер страницы. Обновления SSE сохраняют DOM-узлы карточек и поля ввода. Все внешние метаданные вставляются через textContent, без HTML-инъекций.

Сервер, протокол, сеть, очередь и хранение файлов не меняются. История переезжает в настройки; главный экран показывает текущие ссылки. Цена решения — ручная синхронизация состояний DOM; при существенном росте сложности можно отдельно пересмотреть выбор UI-библиотеки.
