# ADR-0007: Хранение частей, имена выдачи и alpha

Статус: принято, 2026-11-02.

Версия продукта 0.1.0-alpha.1, имя vertov-dl, лицензия исходного кода MPL-2.0. Python distribution version нормализована в 0.1.0a1, публичная версия API/UI/образа — 0.1.0-alpha.1.

Части failed download больше не бессрочны: отдельные настраиваемые лимит 10 ГиБ и TTL 7 дней; при вытеснении задача становится expired. Активные задачи не удаляются. Размер учитывается консервативно по каталогам, включая hardlink входа конвертации. Готовые файлы по-прежнему 10 ГиБ/30 дней.

Оригинальное название сохраняется в БД/UI. Переносимое Unicode-имя формируется только Content-Disposition: NFC, удаление управляющих/emoji, нейтральная пунктуация, Windows reserved names, лимит UTF-8 220 байт с расширением и ID. Путь media.* и manifest докачки остаются стабильными.

Активная выдача удерживает файл через счётчик в Store; Library не удаляет его до завершения HTTP-ответа, включая исключение/разрыв соединения. Гарантия не распространяется на паузу между отдельными Range-запросами.

Один Manager, без multi-user и публичного размещения. break-on-existing исключён. Изменений таблиц SQLite нет.
