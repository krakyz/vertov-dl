# ADR-0005: библиотека и архивирование очереди

Принято, 2026-11-02. Пользователь выбрал 10 ГиБ и 30 дней.

Готовый артефакт продолжает принадлежать download-записи. Удаление из рабочего списка не удаляет запись БД/файл, а устанавливает _queue_hidden в существующем details JSON. API/SSE очереди фильтруют флаг; публичный DTO его не раскрывает. Схема таблиц не меняется, миграция схемы v2 не вводится. Флаг не передаётся новым дочерним задачам и не меняет updated — время завершения и TTL остаются прежними.

Библиотека строится из completed download-записей с существующими файлами, независимо от флага очереди. Worker удаляет старейшие по времени завершения при превышении квоты и по TTL. Отдельный API удаления файла переводит задачу в expired. Исходные URL, cookies и внутренние пути не раскрываются.

Это не хранилище без ограничения общего объёма SQLite/частичных файлов: квота относится к готовым медиа. Аренда артефакта при выдаче и отдельные таблицы/миграции библиотеки остаются возможным следующим этапом.
