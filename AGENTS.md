# Правила работы с репозиторием vertov-dl

- Документация и объяснения пользователю — на русском; идентификаторы кода — на английском.
- Стек ADR-0002/0003: Python/FastAPI + TypeScript/Vite/CSS без React + SQLite + Docker Compose. Rust/Tauri удалены. Системные интеграции исключены.
- Любое изменение поведения сопровождается обновлением соответствующего документа и CHANGELOG.md в том же изменении.
- Разделять реализованное, запланированное и проверенное. Не выдавать макеты за работающую загрузку.
- Архитектурные изменения фиксировать новым ADR. При изменении протокола обновлять docs/remote-protocol.md.
- Remote: сервер получает метаданные, скачивает и объединяет медиа, клиент получает готовый файл. Не переносить прямые CDN URL на домашний клиент.
- WebUI получает файл штатной браузерной загрузкой. Не считать HTTP-ответ подтверждением сохранения на диск. Срок хранения регулируется TTL/ручным удалением.
- Не хранить cookies, токены, подписанные URL, реальные пользовательские ссылки и сырые HTTP-логи в Git, fixtures и журнале изменений.
- Не запускать shell с пользовательскими аргументами. Бинарники запускаются по контролируемому пути с массивом аргументов.
- Не считать HTTP 403 доказательством DPI или CAPTCHA. Не отключать TLS-проверку для восстановления доступа.
- До API удалённых загрузок обязательны авторизация, ограничения ресурсов и защита исходящих соединений, включая redirects/DNS/дочерние процессы.
- Проверки: npm test; npm run build; ruff check apps/api tests scripts; ruff format --check apps/api tests scripts; pytest -q; docker build. Сетевые и process-lifecycle изменения дополнительно проверять в Linux-образе.
- Не запускать несколько uvicorn workers/реплик на одном SQLite volume. Сначала внедрить корректный lease/claim задач.
- Worker сохраняет обязательный proxy без direct fallback. Не обходить gateway для отдельных extractors. FFmpeg в образе обрабатывает только локальные файлы.

- Целевая версия 0.1.0-alpha.2; Python distribution использует 0.1.0a2. Лицензия исходного кода MPL-2.0, сторонние SVG сохраняют собственные лицензии.
- Не переименовывать media_loader, MEDIA_*, cookie-контекст и browser storage keys без миграции: это технические идентификаторы совместимости, не бренд.
